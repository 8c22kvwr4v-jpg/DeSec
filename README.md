# DeSec

Nettside for DeSec — vekterselskap i Bergen og omegn.

Statisk side bygget med HTML, CSS og vanilla JS. Ingen build-steg.

## Kjøre lokalt

```
python3 -m http.server 8080
```

Åpne http://localhost:8080

## Struktur

```
index.html
assets/
  css/style.css
  js/main.js
  img/        (logo og favikoner)
```
